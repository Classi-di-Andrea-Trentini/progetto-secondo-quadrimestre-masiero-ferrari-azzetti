About us

A group project for an Angular course: a full e-commerce site, from the database to the frontend, built from scratch and a few sleepless nights.

The brand

Common Era is a fictional clothing brand created as a realistic scenario for the project. The idea: a minimalist, timeless fashion e-commerce, with a curated collection of clean-design garments and accessories.

There's no company behind the brand — there's a group of three students who built the whole platform from scratch: backend, database, frontend, authentication, admin panel and much more.

The project

This site is the final assignment for the Angular programming course of the 2025–2026 school year. The goal was to build a real web application with Angular, meeting a set of technical requirements: multiple components, routing, APIs, forms, services and guards.

We decided to raise the bar: instead of a minimal project, we built a full e-commerce site with secure session-based authentication, an admin panel, multi-step checkout, a wishlist, reviews, returns and much more.

A word about Claude

For some parts of the project we got help from Claude, Anthropic's AI assistant. In particular for complex debugging, backend architecture, session-based authentication logic, the database seed, and fixing stubborn TypeScript errors.

We used it the way you'd use an experienced colleague — not to write the code for us, but to better understand certain concepts, find hard-to-spot bugs, and talk through architectural choices. Every line of code was reviewed and understood by us.
